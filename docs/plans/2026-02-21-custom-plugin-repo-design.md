# Custom Plugin Repository — Design Document

**Date:** 2026-02-21
**Author:** hnsstrk
**Status:** Approved

## Overview

Ein eigenes Noctalia-Shell-Plugin-Repository auf GitHub (`hnsstrk/noctalia-custom-plugins`), das über die "Benutzerdefiniertes Repository"-Funktion in Noctalia Shell eingebunden wird. Erstes Plugin: Taskwarrior (vollständig spezifiziert in PLAN.md/IMPLEMENTATION.md).

## Anforderungen

- Kompatibel mit Noctalia Shell's Custom-Repository-System
- Automatische Registry-Generierung via GitHub Actions
- Erweiterbar für zukünftige Plugins
- Taskwarrior-Plugin als erstes Plugin veröffentlichen

## Repository-Struktur

```
noctalia-custom-plugins/
├── .github/
│   └── workflows/
│       ├── update-registry.js    # Registry-Generator (vom offiziellen Repo adaptiert)
│       └── update-registry.yml   # GitHub Actions Workflow
├── registry.json                 # Auto-generiert, nie manuell editieren
├── README.md                     # Repo-Beschreibung
├── CLAUDE.md                     # Claude Code Kontext
├── docs/
│   ├── PLAN.md                   # Taskwarrior Design-Dokument
│   └── IMPLEMENTATION.md         # Taskwarrior Implementierungsplan
└── taskwarrior/                  # Erstes Plugin
    ├── manifest.json
    ├── Main.qml
    ├── BarWidget.qml
    ├── Panel.qml
    ├── Settings.qml
    ├── hooks/on-exit-noctalia
    ├── i18n/en.json
    └── README.md
```

## registry.json Format

```json
{
  "version": 1,
  "plugins": [
    {
      "id": "taskwarrior",
      "name": "Taskwarrior",
      "version": "1.0.0",
      "official": false,
      "author": "hnsstrk",
      "description": "A full-featured Taskwarrior client for Noctalia Shell",
      "repository": "https://github.com/hnsstrk/noctalia-custom-plugins",
      "minNoctaliaVersion": "4.1.2",
      "license": "MIT",
      "tags": ["Bar", "Panel", "Productivity", "i18n"],
      "lastUpdated": "<auto-generated>"
    }
  ]
}
```

## GitHub Actions Workflow

- Trigger: Push auf `main` bei Änderungen an `**/manifest.json`
- Script: `update-registry.js` scannt alle Plugin-Verzeichnisse
- Auto-Commit: `chore: update plugin registry [skip ci]`

## Einbindung in Noctalia Shell

1. Noctalia Settings → Plugins → Quellen
2. "+ Benutzerdefiniertes Repository hinzufügen"
3. URL: `https://github.com/hnsstrk/noctalia-custom-plugins`
4. Plugins erscheinen im "Verfügbar"-Tab

## Entscheidungen

- **GitHub als Hoster:** Standard bei allen Noctalia Custom Repos
- **Repo-Name `noctalia-custom-plugins`:** Macht deutlich, dass es ein eigenes Repo ist
- **Ansatz 1 (Standard-Spiegel):** Bewährtes Pattern, kompatibel, erweiterbar
- **GitHub Actions:** Automatische Registry-Updates, kein manueller Aufwand
- **PLAN.md/IMPLEMENTATION.md nach `docs/` verschieben:** Aus dem noctalia-plugins Fork
