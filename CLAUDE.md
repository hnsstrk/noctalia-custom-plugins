# CLAUDE.md

## Project Overview

Custom plugin repository for **Noctalia Shell** — a Linux desktop shell for Wayland compositors. Contains plugins written in **QML/JavaScript** using the **Quickshell** framework.

## Commands

```bash
# Update registry.json from all manifest.json files
node .github/workflows/update-registry.js
```

No build step, test suite, or linter. Plugins are QML files loaded directly by Noctalia Shell at runtime.

## Architecture

### Plugin Layout

Each plugin is a top-level directory containing:

- **`manifest.json`** (required) — plugin metadata, version, entry points, default settings
- **`Main.qml`** — IPC handler and core logic; receives `pluginApi` property
- **`BarWidget.qml`** — status bar icon/widget
- **`Panel.qml`** — popup panel; exposes `contentPreferredWidth/Height` and `allowAttach`
- **`Settings.qml`** — settings UI with `saveSettings()` function
- **`i18n/*.json`** — translations; `en.json` is the reference
- **`README.md`** — plugin documentation

### Registry

`registry.json` is auto-generated by GitHub Actions. Never edit manually.

## Conventions

### Git Commits

Format: `type(scope): message`
Types: `feat`, `fix`, `chore`, `i18n`, `docs`

### i18n

- `en.json` is the source of truth
- Placeholders `{var}` must be preserved in translations
- Key suffixes: `-label`, `-description`, `-placeholder`, `-tooltip`
